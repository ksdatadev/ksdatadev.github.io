Interactive tools

Small, self-contained tools built around ideas I think about. Mostly probability, data, and decision-making.

  • Signed Affinity Recommendation Explorer Interactive
    Compare naive text-embedding cosine similarity against signed weighted-sum matching. Adjust user affinity profiles across eight dimensions and watch the two models diverge in real time.
  • Probability of Success Explorer Interactive
    Compare independent (geometric) vs Bayesian learning models across repeated trials. Adjust base probability, learning rate, and trial count to see how the two models diverge.
